# Telark Homebrew tap

Installs the [`telark`](https://github.com/telark/telark) CLI on macOS and Linux.

```sh
brew install telark/tap/telark
telark version --client
```

Upgrade with `brew upgrade telark`. The commands are described in [docs/CLI.md](https://github.com/telark/telark/blob/main/docs/CLI.md).

The cask in `Casks/` is written by Telark's release workflow on every release, so changes made here by hand are overwritten.
